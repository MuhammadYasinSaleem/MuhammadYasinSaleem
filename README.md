## 🧠 AI & Research Projects

### 🫁 [DiagnoSense — Lung Cancer Detection](https://github.com/MuhammadYasinSaleem/Lung_Cancer_Detection_App)

*Hybrid deep learning architecture for multi-class lung cancer classification using PET/CT scans.*

- Developed a hybrid **ResNet50V2 + Vision Transformer (ViT)** architecture using two-stage transfer learning.
- Achieved **98% test accuracy**, **0.98 macro F1-score**, and **≥ 0.99 AUC** on the LUNG-PET-CT-DX dataset.
- Built a full-stack application using **React, Express.js, and FastAPI** for scan submission and prediction.
- Integrated **LIME explainability** and an AI chatbot to help interpret model predictions.

📄 [Thesis Documentation](https://github.com/MuhammadYasinSaleem/Lung_Cancer_Detection_App/blob/main/model_code/Diagnosense_Thesis.pdf) · 💻 [Model Implementation](https://github.com/MuhammadYasinSaleem/Lung_Cancer_Detection_App/blob/main/model_code/1_Restnet50_%2B_ViT_.ipynb)

### 🧠 [Brain Tumor Classification](https://github.com/MuhammadYasinSaleem/Brain-Tumor-App)

*A hybrid deep learning model for multi-class brain tumor classification from MRI scans.*

- Developed **EffViT-Hybrid**, combining an EfficientNetB0 feature extractor with a ViT-Tiny encoder.
- Classifies MRI scans into four categories: glioma, meningioma, pituitary tumor, and no tumor.
- Built a **FastAPI** application for model inference and prediction.
- Integrated class probabilities and **Grad-CAM** visual explanations for model interpretability.
- Designed for efficient CPU inference, with GPU acceleration available.

### 🩺 [Med-AI — AI-Assisted Healthcare](https://github.com/MuhammadYasinSaleem/Med-AI)

*AI-assisted healthcare solution for patient triage and structured clinical reporting.*

- Developed an AI-driven triage workflow to help identify emergency and high-risk situations early.
- Designed a 15-minute AI-powered patient interview.
- Automatically generated structured **SOAP reports** from patient interviews.
- Helped doctors review patient history and reported symptoms more efficiently.
